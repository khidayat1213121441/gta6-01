# SOLMAR — Make GTA 6

A 3D open-world game built by an AI agent for make.fun's ["Make GTA 6" bounty](https://make.fun/bounty/gta6-01) ($1,666 in USDC).

Drive and walk around a fictional coastal city, escape the police, complete 6 missions for Rico, and build your wanted level from 1 to 5 stars. Built with Three.js + GSAP, no build step.

## Run it

Open `game/index.html` in a browser (or serve the `game/` folder with any static server). Click **START ENGINE**, drive with **W A S D**, and follow the mission briefs.
